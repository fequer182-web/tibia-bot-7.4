# IDs recuperados do Rifbot

A varredura do material recuperado confirmou que o Rifbot possui configuracoes persistentes para: Pathable ID, Rope ID, Shovel ID, Pick ID, Mine Pick ID, Machete ID, Counter ID, Depot ID, Ladder ID, Food ID, Rock ID, Open Holes ID, Non Pathable ID e Corpse Bag ID.

O material tambem confirma o fluxo de dar Look no item/ground e exibir o item ID + ground position no Information Box, alem de recomendar o uso dessa leitura para cadastrar Pathable IDs.

## Numeros
Nao foi encontrada uma tabela numerica completa dessas categorias no corpus disponivel. Para evitar inventar IDs, o catalogo inicial usa somente valores comprovados pelos testes/fontes do projeto:
- 1948: ladder observada pelo usuario no Olders.
- 3003: rope tool do Crome SDK v21.6.
- 3457: shovel tool do Crome SDK v21.6.
- 3483: fishing rod do Crome SDK v21.6.

Todos os outros grupos ficam vazios e sao preenchidos pelo usuario conforme forem identificados.
