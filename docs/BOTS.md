# Catálogo dos bots de Tibia

| Projeto | Caminho | Conteúdo |
| --- | --- | --- |
| Cromin Ancientia DX | [raiz](../README.md) | Painel compacto para a build x86 com leitores, cavebot, ataque por hotkey, loot experimental e luz. |
| Cromin Antica | [legado/antica](../legado/antica) | Painel Python V9 e fontes das ações de ataque, follow, autowalk, loot, food e luz. |
| Crome C++ | [bots/crome-cpp](../bots/crome-cpp) | Painel, runtime, leitores por perfil e referência histórica. Comece em `Crome/Developer`. |
| Ramonia x86 | [research/ramonia_x86](../bots/crome-cpp/research/ramonia_x86) | ResearchProbe, perfil histórico, bridge e CromePipeTest. |
| Cromin Python | [bots/cromin-python](../bots/cromin-python) | Versões Externo, UI e Mini Luz com fontes e testes disponíveis. |
| Cromin C# | [bots/cromin-csharp](../bots/cromin-csharp) | Monitor Antica e variantes de painel, ataque e integração de perfis. |
| Crome no servidor próprio | [bots/crome-servidor](../bots/crome-servidor) | Patch do protótipo TFS, navegação em Lua, Laboratório 100 e variantes Bateria, Corrida, Templo e Sobrevivência. |

O compacto Ancientia continua sendo o ponto de entrada na raiz. As pastas históricas preservam caminhos e versões de origem para consulta. Cada projeto exige sua própria build, dependências e cliente ou servidor. A importação das fontes não revalida os bots históricos no jogo.

Os métodos de diagnóstico ficam no [guia de localização](LOCALIZACAO.md). A coleção cobre os projetos de Tibia encontrados nos trabalhos e pastas locais do Crome e Cromin. Os pacotes de referência Rifbot e o projeto de pet de tela Pestinha ficam fora deste catálogo.
