# Diagnósticos experimentais

`BuildProbe_static.py` lê executáveis em disco. Os scripts `ancientia_*` são coletas por PID para build, jogador, campos pendentes e estados de ataque. Use `--help` em cada script. O observador C++ é código de pesquisa incompleto, sem binário distribuído. Nenhum destes arquivos é iniciado pelo compacto.
